The Computer Deconstruction Laboratory at the InfoAge Science and History Museum offers a free introduction to progamming workshop.
The workshop uses a Arduino Uno to introduce beginners to programming

All of the wiring uses snap circuits https://shop.elenco.com/consumers/brands/snap-circuits.html 


The snap circuits Arduino board is generally not available but can be found from some on line stores
CDL uses a custom designed, 3D printed, board which is compatible with the snap circuits and the Arduino

The programming manual for the Arduino can be found at 
https://www.elenco.com/wp-content/uploads/2017/01/SCSNAPINO_Manual.pdf 

Many other projects can be found at https://www.arduino.cc/maker or by searching for arduino projects with your favorite search engine


This respository contains the files for the workshop

We will offer this workshop to visitors to the Museum
